
# Application de calcul de longueurs - Programme Inox-Mn

Cette application permet de calculer automatiquement :
- La **longueur antenne avec inox**
- La **longueur du rail à couper**
- En fonction d'un **programme Inox-Mn sélectionné**, et des longueurs saisies par l'utilisateur.

## Comment l'utiliser

1. Ouvrir l'application Streamlit :
   - Soit localement avec `streamlit run app_autonome.py`
   - Soit via [Streamlit Cloud](https://share.streamlit.io)

2. Choisir un programme dans la liste déroulante

3. Entrer la **longueur du cœur soudé** (LS) et **la longueur du cœur usiné** (LU)

4. Lire les résultats calculés automatiquement

## Aucune dépendance externe au fichier n'est requise.
Toutes les données sont intégrées dans le script Python.
